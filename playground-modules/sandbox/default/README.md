# 自由沙盒（原始示例）

初始示例工程：内存数组版 Cats 资源，含 AppModule、CatsModule、CatsController 与 CatsService，可自由改写。

## 练习

自由修改、新增模块与路由，保存成你自己的代码版本。

## 运行

在「NestJS 助手 · 操练场」里选中文模块后点「运行」即可；本目录就是该模块的默认代码。

真实项目里的等价命令：

```bash
npm install
npm run start:dev     # 或 npm run build && npm run start:prod
```

## 默认路由

- `GET /cats`
- `GET /cats/1`
